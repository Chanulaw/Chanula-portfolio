# 🚀 Chanula Wijayarathne - Personal Portfolio

A sleek, modern, and responsive personal portfolio web application built with **React**, **Vite**, and **Framer Motion**. Designed with refined typography, glassmorphism aesthetics, fluid animations, and smooth section navigation.

---

## ✨ Features

- **🎨 Modern Glassmorphic Navbar**: Fixed floating navigation header with dynamic backdrop blur, smooth scrolling, and scroll-position active link highlighting.
- **📱 Fully Responsive Design**: Optimized layout across mobile, tablet, and desktop viewports with a responsive mobile menu.
- **⚡ Dynamic Animations**: Micro-interactions and fluid motion powered by **Framer Motion**.
- **📁 Selected Works Showcase**: Highlighted software engineering projects with direct links to GitHub repositories.
- **🏆 Distinctions & Engagements**: Interactive section detailing awards and leadership roles (e.g., AIESEC in CINEC, Richmond Live).
- **📬 Connect Section**: Professional contact details and social links (LinkedIn, WhatsApp, Email, Instagram).

---

## 🛠️ Tech Stack

- **Frontend Framework:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Animation Library:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Styling:** Custom CSS & Flexbox/Grid Architecture
- **Fonts:** Playfair Display & Inter (Google Fonts)

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Chanulaw/my-portfolio.git
   cd my-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

---

## 📦 Build & Deployment

To generate a production build:

```bash
npm run build
```

The compiled output will be located in the `dist/` directory, ready to be deployed on platforms like **Vercel**, **Netlify**, or **GitHub Pages**.
